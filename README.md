# odin-landing-page
This is the second project for the Odin Project, known as Project: Landing Page.
Within this assignment, I will practice the techniques taught in the css and flexbox lessons, which includes creating various styles for text and boxes as well as demonstrating an understanding of nesting and the different attributes that parent and child elements have.
I will also showing an advanced understanding of html for the content on this page.
